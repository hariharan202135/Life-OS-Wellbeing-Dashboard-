# 🌿 Life-OS: AI Wellbeing Dashboard

An AI-powered digital wellbeing dashboard built using **Streamlit**, **Pandas**, and **Google Gemini AI**. **Life-OS** helps users monitor their daily screen time, visualize digital habits, receive personalized AI-powered coaching, and generate a unique AI lifestyle avatar based on their screen usage.

## 📊 Dataset

The application uses a custom **14-day screen time dataset** stored in **`screentime.csv`**.

Each record contains:

* Date
* App Name
* Category
* Minutes Used

The dashboard analyzes the dataset to calculate:

* 📱 Total Screen Time
* 🏆 Most Used App
* 📊 Category-wise Usage
* 📈 Daily Usage Trends

---

## 🤖 AI Wellbeing Coach

The dashboard integrates **Google Gemini AI** to analyze the user's daily screen time habits and provide personalized digital wellbeing recommendations.

The AI generates:

* 📊 Overall Wellbeing Analysis
* 👍 Positive Habits
* ⚠️ Areas of Concern
* 🌿 Healthy Offline Alternatives
* 🎯 Tomorrow's Productivity Challenge
* 💬 Daily Motivation

---

## 🎨 AI Lifestyle Avatar

Based on the user's screen time data, Gemini creates a detailed image prompt that is used to generate an AI-powered lifestyle avatar using **Pollinations AI**.

The generated avatar visually represents the user's digital wellbeing, making the dashboard more engaging and interactive.
