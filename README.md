🌿 Life-OS: AI Wellbeing Dashboard

An AI-powered digital wellbeing dashboard built using Streamlit, Pandas, and Google Gemini AI. Life-OS helps users monitor their daily screen time, visualize digital habits, receive personalized AI coaching, and generate an AI-powered lifestyle avatar that reflects their digital wellbeing.

✨ Features
📊 Interactive Screen Time Dashboard
📅 Date-wise Screen Time Analysis
📈 14-Day Screen Time Trend Visualization
📊 Category-wise Usage Analysis
🎯 Daily Screen Time Goal Tracker
📌 KPI Cards
Total Screen Time
Most Used App
Goal Difference
🤖 AI Wellbeing Coach powered by Google Gemini
🌿 Personalized Productivity & Lifestyle Recommendations
🎨 AI Lifestyle Avatar Generation
⚠️ Smart Wellbeing Alerts
🔔 Interactive Toast Notifications
📱 Clean and Responsive Streamlit Interface

🚀 Installation
Install the required packages
pip install -r requirements.txt
Create a .env file
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
Run the application
streamlit run app.py
📊 Dataset

The application uses a custom 14-day screen time dataset stored in screentime.csv.

Each record contains:

Date
App Name
Category
Minutes Used

The dataset is analyzed to calculate:

Total Screen Time
Most Used App
Category-wise Usage
Daily Usage Trends
🤖 AI Wellbeing Coach

The dashboard uses Google Gemini AI to analyze daily screen time habits and provide personalized recommendations.

The AI generates:

📊 Overall Wellbeing Analysis
👍 Positive Habits
⚠️ Areas of Concern
🌿 Healthier Offline Alternatives
🎯 Tomorrow's Productivity Challenge
💬 Daily Motivation
🎨 AI Lifestyle Avatar

Based on the AI analysis, Gemini creates a detailed image prompt describing the user's digital lifestyle.

The prompt is then used to generate a unique AI lifestyle avatar using Pollinations AI, making the dashboard more engaging and visually appealing.
